Enlaces de interés para desarrollo web

Una pequeña recopilación de sitios que te ayudarán a aprender, comprobar y publicar tus proyectos web.

  • MDN Web Docs en español: la documentación de referencia sobre HTML, CSS y JavaScript.
  • Tutorial de HTML en W3Schools: lecciones cortas con ejemplos que puedes editar y probar.
  • Validador de HTML del W3C: comprueba si tu código cumple el estándar y te indica los errores.
  • GitHub: plataforma para guardar tu código, llevar el control de versiones y publicar páginas.
  • freeCodeCamp en español: cursos gratuitos para aprender programación web desde cero.
