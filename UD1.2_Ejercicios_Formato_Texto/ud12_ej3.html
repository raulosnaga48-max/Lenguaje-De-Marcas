Ficha técnica: Git

Datos generales

Git es un SCV distribuido que creó Linus Torvalds1. Su desarrollo empezó el 7 de abril de 2005. Hoy en día lo usa casi todo el mundo que programa.

Conceptos básicos

Un repositorio es la carpeta donde Git guarda todo el historial de cambios de un proyecto. Se puede manejar desde la terminal o desde un IDE como VSCode.

Comandos útiles

Para añadir los cambios al siguiente commit se usa git add . y para guardarlos git commit -m "mensaje".

Antes de hacer el commit hay que guardar el archivo en el editor con Ctrl + S.

1 Linus Torvalds es también el creador del kernel de Linux.
